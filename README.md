# Keddy EdTech

A modern, responsive EdTech website designed for Keddy, an online learning platform focused on accessible, flexible, and high-quality online tutoring.

## Project Overview

Keddy EdTech is a modern educational platform website designed to provide students with an engaging and user-friendly online learning experience.

The website focuses on:

- Online tutoring
- Flexible learning
- Subject-based learning
- Affordable pricing plans
- Student resources
- Educational content
- Frequently asked questions
- Social media integration

## Key Features

- Modern responsive UI
- Clean and professional EdTech design
- Fully responsive layout
- Hero section with strong CTA
- Online tutoring sections
- Why Choose Keddy section
- Featured tutoring services
- Educational resources
- Pricing packages
- Student testimonials
- FAQ section
- Instagram/social media section
- Contact and footer sections
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Design Focus

The website was designed with a focus on:

- Modern UI/UX
- Clear content hierarchy
- Conversion-focused sections
- Responsive design
- Accessibility
- User-friendly navigation
- Professional educational branding
